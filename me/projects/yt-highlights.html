About

  • Personal project

  • Chrome Web Store

  • 2019 - Present

A Chrome extension that surfaces a video's key moments without leaving the player. It scans the description and top comments for timestamps and turns them into markers on the progress bar - with hover tooltips and next/previous controls - toggled from YouTube's own player settings menu. Published on the Chrome Web Store, open source, with all processing done locally and no data collection.

My role

Solo project, built and maintained since 2019 - plain JavaScript on Manifest V3, no framework. The real work is living inside someone else's app: staying resilient to YouTube's constantly-shifting DOM and single-page navigation, and keeping the footprint small enough (progressive comment loading, debounced DOM work, de-duplicated highlights) that it never affects playback.
